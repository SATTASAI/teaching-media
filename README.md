# teaching-media

คลังสื่อการสอนของโรงเรียนบ้านป่าเด็ง: อัปโหลดไฟล์เข้า Google Drive และจัดเก็บลิงก์สื่อ ด้วยบัญชีเดียวกับระบบโรงเรียน

หน้าเว็บใช้โทนเขียว แฟ้มประเภทไฟล์ด้านซ้าย รายการพร้อมภาพย่อตรงกลาง และตัวอย่างพร้อมรายละเอียดทางขวา รองรับค้นหา จัดเรียง มุมมองรายการ/ตาราง เลือกหลายรายการ และเมนูมือถือ

## ตรวจสอบ

```sh
npm test
node --check public/app.js
node --check public/viewer.js
```

การพัฒนาและ deploy ใช้ Cloudflare Workers ตาม `wrangler.jsonc` พร้อม D1 และการเชื่อมต่อ Google Drive ของระบบเดิม

ภาพประกอบการตรวจหน้าตาใช้ข้อมูลจำลอง ไม่ใช่ข้อมูลผู้ใช้จริง ดูรายละเอียดและข้อจำกัดใน [design-qa.md](design-qa.md)
